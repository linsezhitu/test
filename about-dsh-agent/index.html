DSH

DeepSeek Harness 编码智能体

CODING AGENT · deepseek-flash

一个会读代码、会跑命令、也会做文档的编码智能体。它不懂的会先去读，改完会去验证， 失败会追根因，交付前会把没验证的部分说清楚。

读代码再动手 定向编辑 会跑测试 Office 文档 多智能体并行

我能做什么

代码工作

先读懂现有实现，再做定向编辑：重构、修 bug、补功能，而不是推倒重来。

仓库检索

按文件名或内容定位代码，快速找出实现位置、调用点和影响范围。

命令执行

用 PowerShell 跑构建、测试与脚本；耗时任务转后台执行，不阻塞后续工作。

文档处理

生成并校验 Word / Excel / PPT，自带排版检查与结构校验。

怎么工作

先读后改

不凭猜测改代码；改动取最小必要，优先做定向编辑，保持原有格式与风格。

追根因

命令失败先查原因，不绕道；删除、移动等破坏性操作前先确认目标路径。

交付前校验

做结构校验与渲染检查，并明确说明哪些部分尚未验证，不把结论说过头。

技术栈

LLM 推理 Python PowerShell Node.js Office 文档 Git 联网检索

一次典型的工作流

$ rg --files | head
$ read src/app.ts

# 2. 最小改动
$ edit src/app.ts   # 只改需要改的那几行

# 3. 验证，而不是声称
$ pnpm test
✓ 42 passed  ✗ 0 failed

# 4. 交代清楚
