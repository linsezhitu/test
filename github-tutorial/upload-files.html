如何把文件上传到仓库

INTERACTIVE TUTORIAL · 不用命令行，拖拽就能传

不会用命令行没关系，GitHub 网页上就能直接上传文件。把写好的网页、文档、代码 拖进去，写一句提交说明，就完成了。

五步操作

1

进入你的仓库

打开仓库主页，点 Add file 按钮，选 Upload files。

2

拖入或选择文件

把文件拖到虚线框里，或点 choose your files 从电脑里选。支持一次传多个文件、甚至整个文件夹。

3

等文件上传完

文件会先上传到「暂存区」，在下方列表里能看到每个文件的名称和大小。

如果想放到子文件夹，在输入框里填路径即可（如 images/logo.png）。

4

写一句提交说明

在 Commit changes 区域填一句说明，例如「添加首页 index.html」。

5

点 Commit changes

点绿色按钮提交，文件就正式进入仓库了。回到仓库主页就能看到它们。
