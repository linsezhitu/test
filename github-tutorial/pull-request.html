如何发起 Pull Request

INTERACTIVE TUTORIAL · 协作的核心动作

Pull Request（简称 PR）是 GitHub 协作的灵魂：你在自己的分支上改好了代码， 用 PR「请求」把这些改动合并进主分支，别人可以审阅、讨论，确认没问题再合并。

六步操作

1

建一个分支

不要直接在 main 上改。先新建一个分支，例如 feature/login，在分支上开发。

2

改代码并推送

在分支上做修改，提交（commit）并 push 到 GitHub。

3

点 Compare & pull request

回到仓库主页，GitHub 通常会弹出一个黄色提示条，点 Compare & pull request。

4

写标题和描述

标题一句话说清做了什么；描述里写背景、改动点、如何测试。

5

点 Create pull request

创建 PR，系统会展示这次改动和分支的差异（diff）。

6

审阅后合并

别人（或你自己）审阅通过后，点 Merge pull request 把改动合并进主分支。
