如何用 Issues 提问题

INTERACTIVE TUTORIAL · 项目的留言板

Issue 是仓库自带的「留言板」：发现 bug、想提需求、想讨论方案，都可以开一个 Issue。 写清楚标题和描述，别人就能快速定位并回复你。

五步操作

1

进入 Issues 标签

在仓库主页顶部点 Issues 标签，看到已有的问题列表。

2

点 New issue

点绿色按钮 New issue 新建一个问题。

3

写个清楚的标题

标题用一句话说清问题，例如「登录按钮点击无反应」。别写「救命」这种没信息量的。

4

补充描述

描述里写：发生了什么、怎么复现的步骤、你期望的结果，最好附上截图或报错信息。

可以用 Markdown 排版，比如用 ``` 包住代码片段。

5

提交 Issue

可给 Issue 加标签（Labels）或指派负责人（Assignees），最后点 Submit new issue。

小测验

1. Issue 主要用来做什么？

2. 标题应该怎么写？

3. 描述里最有价值的信息是？
