先分清两件事

Git 和 GitHub 不是一回事，但通常一起出现。

Git —— 版本管理工具

装在你电脑上的一个程序，负责记录文件的每一次改动。你可以随时回到任意一个历史版本，就像游戏存档。

  • 在你本地电脑上运行
  • 不需要联网也能用
  • 核心动作：提交（commit）、分支（branch）

GitHub —— 托管网站

一个网站，用来把 Git 仓库「存到云端」，方便备份、分享和多人协作。

  • 你的仓库存在 GitHub 服务器上
  • 需要联网
  • 核心动作：推送（push）、拉取（pull）、协作（PR）

四个核心概念

仓库 · Repository

一个项目的「文件夹 + 完整历史记录」。本地一份、GitHub 上一份（远程）。

提交 · Commit

给某一时刻的所有改动拍张「快照」，并附一句说明。这是 Git 的基本单位。

分支 · Branch

一条独立的开发线。新功能先在分支上做，稳定后再合并，互不干扰。

远程 · Remote

指向 GitHub 上那个仓库的「地址」。push 是上传，pull 是下载同步。

常用命令速查

命令作用
git init把当前文件夹变成一个 Git 仓库
git status查看当前有哪些改动、处于什么状态
git add .把所有改动加入暂存区
git commit -m "说明"提交一个版本
git push把本地提交推送到 GitHub
git pull从 GitHub 拉取最新内容到本地
git clone <地址>把远程仓库完整复制到本地
git branch查看 / 新建分支
git log查看提交历史

在 GitHub 网页上做这些事

1新建仓库

右上角 + → New repository，填名字、选 Public / Private，点 Create。

 2上传文件

进入仓库 → Add file → Upload files，拖文件进去后提交。

 3发起 Pull Request

分支改完后，网页上点 Compare & pull request，请别人审阅合并。

 4开 Issues

Issues 标签里提问题、报 bug、讨论需求，相当于项目留言板。

 5免费建站

Settings → Pages 把仓库发布成静态网站，得到 xxx.github.io/仓库名 链接。
