如何新建一个 GitHub 仓库

INTERACTIVE TUTORIAL · 30 秒建好你的第一个仓库

仓库（Repository）是你所有代码和文件在 GitHub 上的「家」。新建仓库是一切开始的第一步， 全程在网页上点几下就能完成，不需要命令行。

六步操作

1

点右上角的 + 号

在 GitHub 任意页面的右上角，点 +，在下拉菜单里选 New repository。

2

填写仓库名

在 Repository name 里填名字，建议用小写字母、数字和连字符（如 my-first-project）。

3

写一句描述（可选）

Description 里用一句话说明这个仓库是干嘛的，方便别人看懂。

4

选择公开还是私有

Public 任何人可见；Private 只有你和授权的人可见。

免费账户想用 Pages 建站，记得选 Public。

5

勾选初始化（可选）

勾选 Add a README file 会自带一个说明页；也可以勾选 .gitignore 和许可证。

6

点 Create repository

点绿色按钮，仓库就建好了。接着就可以上传文件或克隆到本地开发。
